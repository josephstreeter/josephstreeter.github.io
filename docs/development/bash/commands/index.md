Reference pages for common Bash commands, each covering syntax, options, and practical examples.

- [cd, pushd and popd](pushd-popd.md) — move around the filesystem

- [rm](rm.md) — remove files and directories

- [cat](cat.md) — concatenate and print files
- [less](less.md) — page through output

- [tail](tail.md) — last lines, and follow
